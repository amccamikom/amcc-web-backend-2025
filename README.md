# 📝 Pertemuan 1: Dasar PHP - AMCC 2026

Selamat datang di repository **AMCC Backend 2026**! Pertemuan pertama ini menjadi langkah awal dalam perjalanan teman-teman untuk memahami dunia **backend development**.

Pada sesi ini, kita akan membahas dasar-dasar **PHP**, bahasa pemrograman yang menjadi fondasi untuk pengembangan aplikasi web dinamis. Kode-kode di dalam repository ini adalah hasil praktikum yang bisa kalian pelajari ulang.

## 🎯 Tujuan Pertemuan

Pada pertemuan ini, peserta diharapkan dapat:
- ✅ Memahami konsep dasar PHP.
- ✅ Menguasai penggunaan variabel, tipe data, dan operator.
- ✅ Menulis program PHP sederhana seperti "Hello World".
- ✅ Mengenal konsep dasar array (Indexed, Associative, Multidimensional).

## 🛠️ Prasyarat (Tools)

Sebelum mencoba kode di repository ini, pastikan kalian sudah menginstall:
1.  **Laragon** (atau XAMPP) sebagai web server lokal.
2.  **Visual Studio Code** sebagai teks editor.
3.  **Web Browser** (Chrome/Edge/Firefox).

## 📂 Materi yang Dibahas

1.  **Program Hello World**: Langkah pertama menampilkan output menggunakan PHP.
2.  **Expression, Statement, Block**: Memahami struktur kode PHP.
3.  **Tipe Data**: Integer, Float, Boolean, dan String.
4.  **Variabel**: Cara mendeklarasikan dan menggunakan variabel (`$namaVar`).
5.  **NULL**: Memahami nilai kosong pada PHP.
6.  **Operator**: Aritmatika, Perbandingan, dan Logika.
7.  **Array**:
    -   *Indexed Array* (Array biasa)
    -   *Associative Array* (Array dengan label)
    -   *Multidimensional Array* (Array di dalam array)

## 🚀 Cara Menjalankan Kode

1.  **Clone/Download** repository ini.
2.  Pindahkan folder hasil download ke dalam folder root server kalian:
    -   Jika pakai **Laragon**: `C:\laragon\www\belajar-php`
    -   Jika pakai **XAMPP**: `C:\xampp\htdocs\belajar-php`
3.  Nyalakan tombol **Start All** di Laragon/XAMPP.
4.  Buka browser dan akses: `localhost/belajar-php` (sesuaikan dengan nama folder).
